Introducción a las cónicas

¿Qué son las cónicas?

Imagina un cono doble (dos conos unidos por la punta) y una hoja de papel que lo corta como si fuera un plano. La curva que queda marcada en el corte es una cónica. Según cómo inclines el plano, aparece una de estas cuatro curvas:

Circunferencia

El plano corta el cono de forma horizontal (perpendicular al eje del cono).

Elipse

El plano se inclina un poco y corta todo alrededor del cono, sin llegar a ser paralelo a un lado.

Parábola

El plano es paralelo a un lado del cono (a una de sus rectas generatrices). La curva no se cierra.

Hipérbola

El plano es más vertical que los lados del cono y corta los dos conos: salen dos ramas.

En cada dibujo, el plano es el rectángulo verde-lima y la curva naranja es la cónica que queda marcada en el cono. Arrastra cada dibujo con el ratón (o con el dedo) para girarlo y verlo desde otros lados.

Cada una tiene una ecuación en x y y. Lo bonito es que las cuatro salen de la misma ecuación general; lo único que cambia son los números (los coeficientes). Eso quiere decir que, con sólo mirar los coeficientes, ya puedes saber de qué cónica se trata sin dibujarla y sin despejar nada.

La ecuación general de segundo grado

Ax² + Bxy + Cy² + Dx + Ey + F = 0

Es de segundo grado porque el exponente más grande que aparece es 2 (en x², en y² o en xy). Las letras mayúsculas son números (los coeficientes), y A, B y C no pueden ser los tres cero a la vez; si lo fueran, la ecuación sería de primer grado y sólo daría una recta.

  • A es el coeficiente de x².
  • B es el coeficiente de xy (el término “mixto”, con las dos letras).
  • C es el coeficiente de y².
  • D y E son los coeficientes de x y de y (los términos de grado 1).
  • F es el término independiente (el número solo).
En este curso: B = 0

En Matemáticas 3 las cónicas tienen sus ejes paralelos a los ejes x y y (no están “giradas”). En ese caso no aparece el término xy, es decir, B = 0, y la ecuación queda más sencilla:

Ax² + Cy² + Dx + Ey + F = 0

Para clasificarla sólo necesitas fijarte en A y C, los coeficientes de x² y y².

¿Por qué funciona así?

Piensa en lo que pasa al completar cuadrados:

  • x² y y² con el mismo signo → quedan una suma de dos cuadrados igualada a un número: (x − h)² + (y − k)² = r² si A = C (circunferencia), o con denominadores distintos si A ≠ C (elipse).
  • x² y y² con signos contrarios → queda una resta de dos cuadrados: (x − h)² − (y − k)² = número (hipérbola).
  • sólo una letra al cuadrado → la otra letra aparece “sola” (con exponente 1): (y − k)² = 4p(x − h) (parábola).

Ejemplos paso a paso

Ejemplo 1

x² + y² − 6x + 4y − 3 = 0
  1. Identifica los coeficientes de x² y de y²: A = 1 y C = 1.
  2. Son iguales (A = C).

Es una circunferencia.

Ejemplo 2

4x² + 9y² − 16x + 18y − 11 = 0
  1. A = 4 y C = 9.
  2. Los dos son positivos (mismo signo) pero diferentes (4 ≠ 9).

Es una elipse.

Ejemplo 3

x² − 4y² − 2x + 8y − 7 = 0
  1. A = 1 y C = −4.
  2. Tienen signos contrarios (AC = −4 < 0).

Es una hipérbola.

Ejemplo 4

y² − 8x + 2y + 9 = 0
  1. No hay término x²: A = 0. El coeficiente de y² es C = 1.
  2. Sólo una de las letras está al cuadrado.

Es una parábola (abre hacia la derecha o la izquierda, porque la que está al cuadrado es y).

Ejemplo 5: ¡cuidado con los signos negativos!

−3x² − 3y² + 12x − 6y + 5 = 0
  1. A = −3 y C = −3.
  2. Son iguales (los dos son −3), aunque sean negativos. Basta con multiplicar toda la ecuación por −1 para ver x² + y² + … = 0.

Es una circunferencia.

Un detalle: las cónicas “degeneradas”

La clasificación por coeficientes dice qué tipo de ecuación es. A veces, al completar cuadrados, la “curva” se reduce a algo más simple. Por ejemplo, x² + y² = 0 es sólo un punto (el origen), x² + y² = −4 no tiene ningún punto (no hay números reales que la cumplan) y x² − y² = 0 son dos rectas que se cruzan. En este curso trabajaremos con las cónicas “de verdad” (no degeneradas).

Resumen

Ax² + Bxy + Cy² + Dx + Ey + F = 0
  • B = 0 y A = C → circunferencia.
  • B = 0, A y C del mismo signo y A ≠ C → elipse.
  • B = 0, A y C de signos contrarios → hipérbola.
  • B = 0 y A = 0 o C = 0 (no los dos) → parábola.
