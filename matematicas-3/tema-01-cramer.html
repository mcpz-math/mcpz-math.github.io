Método de Cramer

El método de Cramer es una técnica de álgebra lineal que permite resolver sistemas de ecuaciones lineales mediante el cálculo de determinantes. Funciona únicamente cuando el sistema tiene el mismo número de ecuaciones que de incógnitas y el determinante principal es distinto de cero.

Objetivo general

Desarrollar en el estudiante la capacidad para resolver sistemas de ecuaciones lineales mediante el método de Cramer, utilizando de manera correcta los determinantes y procedimientos algebraicos para obtener los valores de las incógnitas, así como interpretar y verificar los resultados, fortaleciendo el razonamiento lógico, la resolución de problemas y el pensamiento matemático.

Antecedentes. Revisa en tus apuntes del curso de Matemáticas I y Matemáticas II lo siguiente:

  • Operaciones básicas de los números enteros (suma, resta, multiplicación y división).
  • Operaciones básicas de los números racionales (suma, resta, multiplicación y división).
  • Leyes de los signos para esas operaciones básicas.

Empecemos definiendo qué es un determinante. Un determinante es un número que se obtiene a partir de una matriz cuadrada y que proporciona información importante sobre ella. En el tema de sistemas de ecuaciones, el determinante permite saber, entre otras cosas, si un sistema tiene una solución única y es fundamental para aplicar el método de Cramer.

Determinante

Δ = abcd = ad − bc

Observación

Cuando el determinante principal es cero decimos que el sistema no tiene solución o tiene un infinito de soluciones.

Procedimiento

  1. Observa que las ecuaciones estén ordenadas de acuerdo a la variable.
  2. Establece el determinante principal y resuélvelo.
  3. Si el determinante es distinto de cero, encuentra el determinante para la primera incógnita, divide entre el valor obtenido del determinante principal y resuelve.
  4. Repite el paso anterior para todas las incógnitas.
  5. Comprueba si hemos llegado a la solución.

Ejemplo resuelto

Resolver el siguiente sistema de ecuaciones por el método de Cramer

4x − y = 5 2x + 5y = −1

Paso 1. Observamos que en el sistema primero están las x's y después las y's.

Paso 2. Determinante principal:

Δ = 4−125 = 20 + 2 = 22

Paso 3. Para la incógnita x:

x = Δx / Δ = 5−1−15 22 = (25 − 1) / 22 = 24/22 = 12/11

Paso 4. Para la incógnita y:

y = Δy / Δ = 452−1 22 = (−4 − 10) / 22 = −14/22 = −7/11

Por lo que la solución es: x = 12/11 y y = −7/11.

Paso 5. Comprobación. Sustituimos los valores encontrados en ambas ecuaciones. Si en ambas nos queda la igualdad, hemos encontrado la solución del sistema.

Ecuación 1

4x − y = 5
4(12/11) − (−7/11) = 5
48/11 + 7/11 = 5
55/11 = 5 ✓

Ecuación 2

2x + 5y = −1
2(12/11) + 5(−7/11) = −1
24/11 − 35/11 = −1
−11/11 = −1 ✓

Observación

Este método puede generalizarse para sistemas de ecuaciones de 3×3, 4×4, 5×5, etc.
