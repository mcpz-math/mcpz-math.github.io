Completar el trinomio cuadrado perfecto

Conocimiento previo

Repaso

Completar un trinomio cuadrado perfecto usa lo que ya viste: el binomio al cuadrado (a ± b)² = a² ± 2ab + b² y cómo se factoriza un TCP. Si ya se te olvidó, repásalo antes de empezar.

Repasar binomio al cuadrado y TCP →

¿Qué significa «completar»?

Mira el trinomio x² + 6x + ___. Le falta el último término. Si ese término es el correcto, el trinomio será un trinomio cuadrado perfecto (TCP): un binomio al cuadrado. Como (x + 3)² = x² + 6x + 9, el término que falta es 9.

Se le llama completar el cuadrado porque se puede ver como un cuadrado al que le falta una esquina: x² y dos rectángulos de 3 · x forman casi un cuadrado de lado x + 3, y la esquina que falta es un cuadradito de 3 · 3 = 9.

Cómo se completa un TCP: x² + bx + ___

En x² + bx + ___, el número b es el que acompaña a la x, con su signo. Para saber qué término falta:

  1. Identifica b (con su signo).
  2. Divídelo entre 2: b2.
  3. Elévalo al cuadrado: (b2)². Ése es el término que falta, y siempre es positivo.
  4. Escribe el trinomio completo y factorízalo: el binomio es (x + b2)², con el signo de b.
  • x² + bx + (b2)² = (x + b2)²

Esto es lo mismo que la regla del TCP al revés: el término de en medio es el doble producto 2ab con a = x, así que b = 2 · (el número del binomio). Por eso el número del binomio es la mitad de b, y el último término es ese número al cuadrado.

Ejemplos

Cuatro ejemplos paso a paso

  • x² + 8x + ___: b = 8 → b ÷ 2 = 4 → 4² = 16. Queda x² + 8x + 16 = (x + 4)².
  • x² − 10x + ___: b = −10 → b ÷ 2 = −5 → (−5)² = 25 (positivo). Queda x² − 10x + 25 = (x − 5)².
  • x² + 5x + ___: b = 5 → b ÷ 2 = 52 → (52)² = 254. Queda x² + 5x + 254 = (x + 52)².
  • x² − x + ___: b = −1 → b ÷ 2 = −12 → (−12)² = 14. Queda x² − x + 14 = (x − 12)².

Errores comunes: usar b² en lugar de (b ÷ 2)² (x² + 6x + 36 no es un TCP); sumar b ÷ 2 sin elevarlo al cuadrado; y poner el signo de b en el último término (siempre es positivo: el signo de b va en el binomio).

¿Para qué sirve?

Completar el cuadrado permite resolver ecuaciones que no se factorizan a simple vista. Por ejemplo, en x² + 6x = 7 sumamos 9 en los dos lados (el término que completa el TCP) y queda:

  • x² + 6x + 9 = 7 + 9
  • (x + 3)² = 16
  • x + 3 = ±4 → x = 1 o x = −7

También es la idea que da la fórmula general de las ecuaciones de segundo grado y el vértice de una parábola.

Ejercicios: completa el TCP (falta el último término)

Instrucciones

A cada trinomio x² + bx + ___ le falta el último término. Contesta los tres pasos y oprime Comprobar (o la tecla Enter):

1. ¿Cuánto vale b ÷ 2? (b es el número que acompaña a la letra, con su signo)
2. ¿Qué término falta? Es (b ÷ 2)² y siempre es positivo.
3. Factoriza el trinomio completo: escribe el binomio al cuadrado, por ejemplo (x + 3)^2.

Los números pueden ser enteros, fracciones (por ejemplo 5/2) o decimales. Debajo de cada casilla hay botones para escribir la letra, los paréntesis, el ², el signo menos y la fracción; también puedes usar ^2 con el teclado.

Te tocan 10 ejercicios al azar de un banco de 100. Cuando termines, oprime Otros 10 ejercicios para volver a intentar con ejercicios diferentes.

Ejercicios: completa el TCP (falta el término de en medio)

Instrucciones

Ahora el que falta es el término de en medio, por ejemplo x² + ___ + 49. Contesta los tres pasos y oprime Comprobar:

1. ¿Cuánto vale la raíz cuadrada del último término?
2. ¿Qué término de en medio falta? Es el doble producto 2 · x · (la raíz). Hay dos respuestas posibles, con signo + o con signo −: escribe una, por ejemplo 14x o −14x.
3. Factoriza el trinomio que formaste: (x + 7)^2 si elegiste +14x, o (x − 7)^2 si elegiste −14x.

Te tocan 10 ejercicios al azar de un banco de 50. Oprime Otros 10 ejercicios para volver a intentar con ejercicios diferentes.
