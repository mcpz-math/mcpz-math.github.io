Factorizar trinomios de la forma x² + bx + c

Conocimiento previo

Repaso

Factorizar x² + bx + c es deshacer la multiplicación de dos binomios con un término común, (x + a)(x + b) = x² + (a + b)x + ab. Antes de empezar, repasa ese tema. Un caso especial de estos trinomios es el trinomio cuadrado perfecto, como x² + 6x + 9 = (x + 3)², que verás con más detalle al final de este tema.

1. Binomio factor común →

¿Qué es un trinomio de la forma x² + bx + c?

Es un trinomio donde el coeficiente del término x² es 1 (pero casi nunca se escribe), el término con x tiene un número b y el último término es un número c. Por ejemplo:

  • x² + 7x + 12  (b = 7, c = 12)
  • x² − 9x + 20  (b = −9, c = 20)
  • x² + 2x − 15  (b = 2, c = −15)

Factorizar es escribirlo como un producto de dos binomios, (x + p)(x + q). Para saber cuáles son p y q, primero hay que ver de dónde sale el trinomio.

¿De dónde sale? Al multiplicar dos binomios

Multipliquemos (x + 3)(x + 4), término a término (si quieres practicar esta multiplicación, está en Binomio factor común):

  • (x + 3)(x + 4) = x² + 4x + 3x + 12
  • = x² + 7x + 12

El 7 es la suma de 3 y 4 (4x + 3x = 7x) y el 12 es su producto (3 · 4). Pasa siempre:

  • (x + p)(x + q) = x² + (p + q)x + p · q

Al revés: cómo se factoriza x² + bx + c

Factorizar es volver atrás: dado x² + bx + c hay que encontrar dos números p y q tales que:

  • su producto nos dé el tercer término (c): p · q = c,
  • su suma sea el coeficiente del segundo término (b): p + q = b.

Y entonces el trinomio se factoriza como (x + p)(x + q).

Los pasos:

  1. Revisa que el coeficiente de x² sea 1 (aunque no se escriba) e identifica b y c, con su signo.
  2. Escribe los pares de números enteros cuyo producto es c.
  3. Elige el par cuya suma es b.
  4. Escribe (x + p)(x + q), con el signo de cada número.
  5. Comprueba multiplicando los binomios: debe quedar el trinomio original.

Los signos ayudan a buscar:

  • Si c es positivo, p y q tienen el mismo signo (el de b): los dos positivos si b es positivo; los dos negativos si b es negativo.
  • Si c es negativo, p y q tienen signos diferentes; el que tiene mayor valor absoluto lleva el signo de b.

Ejemplos

Cuatro ejemplos paso a paso

  • x² + 7x + 12: c = 12 es positivo y b = 7 es positivo, así que los dos números son positivos. Pares con producto 12: 1 y 12 (suma 13), 2 y 6 (suma 8), 3 y 4 (suma 7) ✓. Queda (x + 3)(x + 4).
  • x² − 9x + 20: c = 20 es positivo y b = −9 es negativo, así que los dos números son negativos. Pares con producto 20: −1 y −20 (suma −21), −2 y −10 (suma −12), −4 y −5 (suma −9) ✓. Queda (x − 4)(x − 5).
  • x² + 2x − 15: c = −15 es negativo, así que los números tienen signos diferentes, y el mayor lleva el signo de b = 2 (positivo). Pares: −1 y 15 (suma 14), −3 y 5 (suma 2) ✓. Queda (x − 3)(x + 5).
  • x² − 5x − 14: c = −14 es negativo y b = −5 es negativo, así que el número mayor es el negativo. Pares: 1 y −14 (suma −13), 2 y −7 (suma −5) ✓. Queda (x + 2)(x − 7).

Comprobación del último: (x + 2)(x − 7) = x² − 7x + 2x − 14 = x² − 5x − 14 ✓.

Casos especiales

  • Los dos números son iguales (p = q): es un trinomio cuadrado perfecto. x² + 6x + 9: 3 y 3 → (x + 3)(x + 3) = (x + 3)².
  • Los dos números son opuestos (p = −q): no hay término con x (b = 0) y es una diferencia de cuadrados. x² − 25: 5 y −5 → (x + 5)(x − 5).
  • No hay ningún par que sirva: el trinomio no se puede factorizar con números enteros. En x² + 4x + 5 los pares con producto 5 son 1 y 5 (suma 6) y −1 y −5 (suma −6): ninguno suma 4.

Errores comunes: elegir un par que multiplicado da c pero que no suma b; olvidar el signo de uno de los números (en x² − 5x − 14 el 7 es negativo y el 2 es positivo, no al revés); y escribir (x + 3)(x + 4) como si fuera x² + 12 o x² + 7: hay que fijarse en las dos condiciones a la vez.

¿Y si no hay números enteros que sirvan? La fórmula general

Buscar dos números p y q (con p · q = c y p + q = b) sólo encuentra números enteros, y no siempre existen. Mira x² + 4x + 1: los pares con producto 1 son 1 y 1 (suma 2) y −1 y −1 (suma −2); ninguno suma 4, así que no se puede factorizar con números enteros.

¿Quiere decir que la ecuación x² + 4x + 1 = 0 no tiene solución? No. Sí la tiene, pero no son números enteros: x = −2 + √3 ≈ −0.27 y x = −2 − √3 ≈ −3.73. Y hay trinomios, como x² + 4x + 5, cuyas soluciones ni siquiera son números reales (usan la i).

¿Por qué necesitamos una fórmula?

  • Buscar pares es probar y adivinar. Si no encuentras ninguno, no sabes si de verdad no hay solución o si te faltó probar un par (con un c grande, como 360, hay muchísimos pares).
  • Los pares sólo dan soluciones enteras. Las soluciones con raíz (√) o con i no se pueden «adivinar» buscando números.
  • Necesitamos un método que siempre funcione, con cualquier b y c, y que además nos diga qué clase de soluciones hay. Ese método es la fórmula general.

La fórmula general

Fórmula general

Las soluciones de ax² + bx + c = 0 son

x = −b ± √b² − 4ac2a

Primero a = 1 (el coeficiente de x² es 1, pero casi nunca se escribe), así que queda x = −b ± √b² − 4c2.

¿De dónde sale? De completar el cuadrado (una idea que verás con detalle en Completar el trinomio cuadrado perfecto, el siguiente tema). Con a = 1:

  • x² + bx + c = 0
  • x² + bx = −c  (pasamos c al otro lado)
  • x² + bx + b²4 = b²4 − c  (sumamos lo que completa el TCP)
  • (x + b2)² = b² − 4c4  (factorizamos el TCP)
  • x + b2 = ± √b² − 4c2  (raíz cuadrada de los dos lados)
  • x = −b ± √b² − 4c2

El discriminante: ¿qué clase de soluciones hay?

Lo que está debajo de la raíz se llama discriminante: Δ = b² − 4ac (cuando a = 1, Δ = b² − 4c). Antes de terminar la cuenta ya te dice qué esperar:

  • Δ es un cuadrado perfecto (1, 4, 9, 16, 25…): √Δ es un número entero y las soluciones son enteras. El trinomio sí se factoriza con números enteros (son los ejercicios de arriba en los que sí encontraste el par p y q).
  • Δ = 0: una sola solución, repetida. Es un trinomio cuadrado perfecto, como x² + 6x + 9 (Δ = 36 − 36 = 0).
  • Δ > 0 pero no es cuadrado perfecto (2, 3, 5, 8, 12…): dos soluciones reales con raíz (√). El trinomio no se puede factorizar con números enteros.
  • Δ < 0: dos soluciones imaginarias, con i: √(−n) = √n · i. La parábola de y = x² + bx + c no corta el eje x.

Por eso, cuando en los ejercicios de arriba oprimes «No se puede factorizar con números enteros», la fórmula general es la que te da las soluciones.

Los pasos con la fórmula general

  1. Escribe la ecuación x² + bx + c = 0 e identifica b y c, con su signo (a = 1).
  2. Calcula el discriminante: Δ = b² − 4c. Recuerda que b² nunca es negativo, aunque b lo sea, y que si c es negativo, −4c suma.
  3. Sustituye en x = (−b ± √Δ) ÷ 2. Cuidado con el signo de −b: si b = −6, entonces −b = 6.
  4. Simplifica la raíz: busca el cuadrado perfecto más grande que divida a Δ (√12 = √(4 · 3) = 2√3). Si Δ es negativo, √(−n) = √n · i.
  5. Divide los dos términos del numerador entre 2 (si se puede) y escribe las dos soluciones, x₁ (con +) y x₂ (con −).

Cinco ejemplos paso a paso

  • x² + 4x + 1 = 0 (b = 4, c = 1). Δ = 4² − 4(1)(1) = 16 − 4 = 12, positivo y no es cuadrado perfecto. x = −4 ± √122. Simplificamos: √12 = √(4 · 3) = 2√3, y queda −4 ± 2√32 = −2 ± √3. Soluciones: x₁ = −2 + √3 ≈ −0.27 y x₂ = −2 − √3 ≈ −3.73.
  • x² + 3x + 1 = 0 (b = 3, c = 1). Δ = 3² − 4(1)(1) = 9 − 4 = 5. √5 ya no se simplifica y 3 es impar, así que x = −3 ± √52. Soluciones: x₁ = −3 + √52 ≈ −0.38 y x₂ = −3 − √52 ≈ −2.62.
  • x² − 2x − 7 = 0 (b = −2, c = −7). Cuidado con los signos: Δ = (−2)² − 4(1)(−7) = 4 + 28 = 32, y −b = −(−2) = 2. x = 2 ± √322. √32 = √(16 · 2) = 4√2, y queda 2 ± 4√22 = 1 ± 2√2. Soluciones: x₁ = 1 + 2√2 y x₂ = 1 − 2√2.
  • x² + 4x + 5 = 0 (b = 4, c = 5). Δ = 4² − 4(1)(5) = 16 − 20 = −4, negativo: las soluciones son imaginarias. x = −4 ± √(−4)2, y √(−4) = √4 · i = 2i, así que x = −4 ± 2i2 = −2 ± i. Soluciones: x₁ = −2 + i y x₂ = −2 − i.
  • x² + 7x + 12 = 0 (para comparar con lo de arriba). Δ = 7² − 4(1)(12) = 49 − 48 = 1, un cuadrado perfecto. x = −7 ± 12: x₁ = −3 y x₂ = −4. Son los mismos números que encontramos con los pares: (x + 3)(x + 4). La fórmula funciona siempre, y Δ cuadrado perfecto avisa que sí se factoriza con enteros.

Con las soluciones también se factoriza: x² + bx + c = (x − x₁)(x − x₂). Por ejemplo, x² + 4x + 1 = (x − (−2 + √3))(x − (−2 − √3)) = (x + 2 − √3)(x + 2 + √3).

Errores comunes: olvidar el signo de −b (si b = −2, −b = 2); calcular (−2)² como −4 (es 4); restar en lugar de sumar cuando c es negativo (−4 · 1 · (−7) = +28); dividir entre 2 sólo un término del numerador (en 2 ± 4√22 se dividen el 2 y el 4); dejar √12 sin simplificar; olvidar el ± (son dos soluciones); y, cuando Δ es negativo, olvidar la i.

Ejercicios: resuelve con la fórmula general

Instrucciones

Estos trinomios no se pueden factorizar con números enteros (Δ no es un cuadrado perfecto). Resuelve cada ecuación x² + bx + c = 0 con la fórmula general y contesta en las tres casillas:

1. Escribe el discriminante Δ = b² − 4c.
2. Escribe las dos soluciones, ya simplificadas y en cualquier orden. Si Δ es negativo, usa la i.

Escribe la raíz con el botón √ (por ejemplo −2 + √3 o 2√2) y las fracciones con / (por ejemplo (−3 + √5)/2); con i: −2 + i. Debajo de las casillas hay botones para escribir la raíz, la i, los paréntesis y los signos. Oprime Comprobar (o la tecla Enter).

La fórmula general cuando a no es 1: ax² + bx + c

Hasta aquí el término x² no tenía coeficiente (a = 1). Pero muchos trinomios son como 2x² + 5x + 2, 3x² − 2x − 2 o −x² + 4x − 1. Con ellos ya no sirve buscar dos números con p + q = b y p · q = c: hay que probar combinaciones de a y de c, y el tanteo se vuelve largo y difícil.

La fórmula general sí funciona igual; sólo cambia que ahora a ya no vale 1 y que el denominador es 2a (no sólo 2):

Fórmula general

x = −b ± √b² − 4ac2a

con Δ = b² − 4ac. Recuerda que a nunca puede ser 0 (si no, ya no sería una ecuación cuadrática).

Cosas nuevas que cuidar:

  • a puede ser negativo (como en −x² + 4x − 1): sustitúyelo con su signo. Si el denominador queda negativo, cambia el signo del numerador y del denominador.
  • El discriminante ahora usa a: Δ = b² − 4ac. Si a y c tienen el mismo signo, −4ac resta; si tienen signos diferentes, suma.
  • Al final se simplifica la fracción: si todos los términos del numerador y el denominador se pueden dividir entre el mismo número, se divide.
  • Si Δ es un cuadrado perfecto, las soluciones son fracciones o enteros (sin raíz) y el trinomio sí se factoriza con coeficientes enteros. Si Δ = 0, hay una sola solución, repetida. Si Δ no es cuadrado perfecto, hay raíces; si Δ < 0, las soluciones llevan i.

Cinco ejemplos con a distinta de 1

  • 2x² + 5x + 2 = 0 (a = 2, b = 5, c = 2). Δ = 5² − 4(2)(2) = 25 − 16 = 9, un cuadrado perfecto: √9 = 3. x = −5 ± 34, así que x₁ = −5 + 34 = −24 = −12 y x₂ = −5 − 34 = −2. Como Δ es cuadrado perfecto, sí se factoriza: 2x² + 5x + 2 = (2x + 1)(x + 2), y la fórmula lo encontró sin tanteos.
  • 3x² − 2x − 2 = 0 (a = 3, b = −2, c = −2). Δ = (−2)² − 4(3)(−2) = 4 + 24 = 28. √28 = √(4 · 7) = 2√7. x = 2 ± 2√76; dividimos numerador y denominador entre 2 y queda 1 ± √73. Soluciones: x₁ = 1 + √73 ≈ 1.22 y x₂ = 1 − √73 ≈ −0.55.
  • 2x² + 2x + 1 = 0 (a = 2, b = 2, c = 1). Δ = 2² − 4(2)(1) = 4 − 8 = −4, negativo: soluciones imaginarias. √(−4) = 2i. x = −2 ± 2i4 = −1 ± i2 (dividimos entre 2). Soluciones: x₁ = −1 + i2 y x₂ = −1 − i2.
  • −x² + 4x − 1 = 0 (a = −1, b = 4, c = −1). Cuidado con los signos: Δ = 4² − 4(−1)(−1) = 16 − 4 = 12, y √12 = 2√3. x = −4 ± 2√3−2. El denominador es negativo, así que dividimos cada término entre −2: −4 ÷ (−2) = 2 y ± 2√3 ÷ (−2) = ∓ √3. Queda 2 ∓ √3. Soluciones: x₁ = 2 + √3 ≈ 3.73 y x₂ = 2 − √3 ≈ 0.27.
  • 4x² − 12x + 9 = 0 (a = 4, b = −12, c = 9). Δ = (−12)² − 4(4)(9) = 144 − 144 = 0. Con Δ = 0 no hay raíz que sumar ni restar: x = 128 = 32. Hay una sola solución, x = 32 (repetida), porque 4x² − 12x + 9 es un trinomio cuadrado perfecto: (2x − 3)².

Errores comunes: dividir entre 2 en lugar de entre 2a (en 2x² + 5x + 2 el denominador es 4, no 2); olvidar a en −4ac; perder el signo de a o de c; simplificar sólo un término del numerador (en 2 ± 2√76 se divide el 2 y el 2√7, y también el 6); y, cuando Δ = 0, escribir dos soluciones diferentes.

Ejercicios: fórmula general con a distinta de 1

Instrucciones

Resuelve cada ecuación ax² + bx + c = 0 con la fórmula general y contesta en las tres casillas:

1. Escribe el discriminante Δ = b² − 4ac.
2. Escribe las dos soluciones, ya simplificadas y en cualquier orden. Si Δ = 0, escribe la misma solución en las dos casillas. Si Δ es negativo, usa la i.

Las fracciones se escriben con / (por ejemplo −1/2 o (1 + √7)/3) y la raíz con el botón √ (por ejemplo 2 + √3). Si Δ es un cuadrado perfecto, las soluciones son números enteros o fracciones, sin raíz. Oprime Comprobar (o la tecla Enter).
