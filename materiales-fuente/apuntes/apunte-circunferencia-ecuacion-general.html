Circunferencia: de la ecuación general al centro y al radio

¿Cómo sé que es una circunferencia?

En la ecuación general de segundo grado, es circunferencia cuando los coeficientes de x² y de y² son iguales (A = C) y no hay término xy.

  • Si A = C = 1, ya tiene la forma x² + y² + Dx + Ey + F = 0.
  • Si A = C ≠ 1 (por ejemplo, 3x² + 3y² + …), divide toda la ecuación entre A.

Completar cuadrados

(x + a)² = x² + 2ax + a²
El coeficiente de x es 2a. Para completar el cuadrado de x² + Dx: a es la mitad del coeficiente de x y hay que sumar a².
  • x² − 6x: la mitad de −6 es −3 y (−3)² = 9 → x² − 6x + 9 = (x − 3)².
  • y² + 4y: la mitad de 4 es 2 y 2² = 4 → y² + 4y + 4 = (y + 2)².
Para no equivocarteLo que sumas de un lado de la igualdad, súmalo también del otro lado. El signo del binomio es el mismo signo del coeficiente de x (o de y).

Pasos para encontrar el centro y el radio

  1. Si hace falta, divide entre A para que los coeficientes de x² y de y² sean 1.
  2. Agrupa los términos en x, los términos en y, y pasa F al lado derecho (con signo cambiado).
  3. Completa el cuadrado en x y en y, sumando a los dos lados la mitad del coeficiente elevada al cuadrado.
  4. Escribe cada trinomio como binomio al cuadrado y suma los números de la derecha: (x − h)² + (y − k)² = r².
  5. Lee el centro (h, k) (signos contrarios a los de los paréntesis) y el radio r = √(r²).

Ejemplos

1. x² + y² − 6x + 4y − 3 = 0

(x² − 6x) + (y² + 4y) = 3 → (x² − 6x + 9) + (y² + 4y + 4) = 3 + 9 + 4 → (x − 3)² + (y + 2)² = 16.
Centro (3, −2) y radio 4.

2. x² + y² + 4x − 10y + 20 = 0

(x² + 4x + 4) + (y² − 10y + 25) = −20 + 4 + 25 → (x + 2)² + (y − 5)² = 9.
Centro (−2, 5) y radio 3.

3. Cuando falta un término: x² + y² − 8x − 9 = 0

(x² − 8x + 16) + y² = 9 + 16 → (x − 4)² + y² = 25.
Centro (4, 0) y radio 5.

4. Cuando los coeficientes no son 1: 3x² + 3y² − 12x + 6y − 12 = 0

A = C = 3: divide entre 3 → x² + y² − 4x + 2y − 4 = 0 → (x² − 4x + 4) + (y² + 2y + 1) = 4 + 4 + 1 → (x − 2)² + (y + 1)² = 9.
Centro (2, −1) y radio 3.

¿Siempre sale una circunferencia?

Lado derecho (r²)Qué representa
positivoUna circunferencia, con radio r = √(r²).
ceroUn solo punto: el centro (h, k). Ejemplo: x² + y² − 2x + 4y + 5 = 0 → (x − 1)² + (y + 2)² = 0, el punto (1, −2).
negativoNingún punto (un cuadrado nunca es negativo). Ejemplo: x² + y² + 2x + 2y + 5 = 0 → (x + 1)² + (y + 1)² = −3.

Un atajo con fórmulas (para revisar)

Completando cuadrados con letras en x² + y² + Dx + Ey + F = 0:
h = −D2    k = −E2    r² = h² + k² − F
Con el ejemplo 1 (D = −6, E = 4, F = −3): h = −−62 = 3, k = −42 = −2, r² = 9 + 4 + 3 = 16 → r = 4 ✓. El procedimiento que debes escribir es el de completar cuadrados; las fórmulas sirven para revisar.

Resumen

  • Es circunferencia si A = C y no hay término xy (si A = C ≠ 1, divide entre A).
  • Completa cuadrados en x y en y, sumando lo mismo a los dos lados, para llegar a (x − h)² + (y − k)² = r².
  • Centro (h, k) con signos contrarios a los de los paréntesis; radio = raíz positiva de r².
  • r² positivo: circunferencia · r² = 0: un punto · r² negativo: ningún punto.
